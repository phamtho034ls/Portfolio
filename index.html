01

Applied AI System

RAG / LLM / LEGAL AI

Government AI Copilot — Trợ lý tra cứu pháp luật

Hệ thống RAG tra cứu văn bản pháp luật Việt Nam — tìm đúng văn bản, đúng điều khoản, trả lời có căn cứ rõ ràng.

Pipeline kết hợp semantic search + full-text search, hợp nhất bằng RRF và reranking, xử lý truy vấn với query rewriting và routing. Quản lý hội thoại đa lượt, cache và validation để giảm thiểu hallucination.

Công nghệ: Python · FastAPI · PostgreSQL · Qdrant · Redis · React · Sentence Transformers · OpenAI API

Kỹ thuật: Hybrid Retrieval · RRF · Reranking · Query Rewriting · Query Routing · AI Agent · Answer Validation · Legal Citation

Private Project

OCR / DOCUMENT AI

OCR_V3 — Vietnamese Document Intelligence

Hệ thống OCR và Document Intelligence số hóa tài liệu tiếng Việt: CCCD, hồ sơ nhà đất, PDF và các biểu mẫu cần trích xuất dữ liệu có cấu trúc.

Pipeline đầy đủ từ upload → image preprocessing → OCR → parsing → validation → export kết quả. Tích hợp authentication, phân quyền và quản lý trạng thái job xử lý.

Công nghệ: Python · FastAPI · PostgreSQL · React · OpenCV · Docker

Kỹ thuật: Vietnamese OCR · CCCD Processing · PDF Processing · Structured Extraction · Data Validation · Job Management · Authentication · Export Pipeline

Applied AI System

COMPUTER VISION / BIOMETRICS

Face AI — Face Enrollment & Verification

Microservice nhận diện và xác thực khuôn mặt cho luồng đăng ký người dùng và chấm công.
