# Phạm Ngọc Thọ — AI Engineer Portfolio

Static, responsive portfolio in one HTML file. CSS and JavaScript are inline; there is no build step or dependency install.

## Run locally

From the project directory:

```bash
python3 -m http.server 8000
```

Open <http://localhost:8000>. Stop the server with `Ctrl+C`.

## Check

```bash
node --test tests/portfolio.test.js
```

Project visuals are illustrative diagrams. The OCR_V3 repository is private and has no public source or demo link.
